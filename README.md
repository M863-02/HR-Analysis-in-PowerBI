# HR Analysis in PowerBI
# Overview 
This project is an HR Analytics Dashboard developed using Microsoft Power BI to provide complete insights into an organization’s workforce.
The dashboard enables HR teams and management to monitor employee distribution, promotion eligibility, retrenchment readiness, workforce composition, and experience levels through interactive and visually intuitive reports.
# Objective
- Analyze total workforce and gender distribution
- Identify employees due for promotion and retrenchment
- Track employee experience through service years
- Understand job level distribution
- Analyze employee distance from office
- Support strategic HR decision-making
# Tools & Technologies
- Microsoft Power BI Desktop

- Power Query
  - Data cleaning and transformation
  - Handling null values
  - Data type standardization

- DAX (Data Analysis Expressions)
  - Calculated measures
  - KPIs and percentage calculations

- CSV Files as data source

# Data Preparation & Modeling
- Imported CSV files into Power BI
- Cleaned and transformed data using Power Query
- Created calculated columns and measures using DAX, such as:
- Total Employees
- Active Workers
- Employees Due for Promotion
- Employees Due for Retrenchment
- Gender-wise percentages
- Built relationships for accurate aggregation and filtering

# Dashboard Features
🔹 Key KPIs
- Total Employees: 1,470
- Male Employees: 882 (60%)
- Female Employees: 588 (40%)
- Active Workers: 1,353 (92%)
- Next Retrenchment: 117 (8%)
- Due for Promotion: 72 (4.9%)

🔹 Visual Insights

- Gender distribution of employees
- Service years distribution
- Employees due for promotion 
- Employees due for retrenchment 

🔹 Interactive Pages

- Home: Overall workforce insights and KPIs
- Action: Employees requiring promotion or retrenchment actions
- Detail: Detailed employee-level information

# Key Insights

- Only 4.9% of employees are currently due for promotion

- 8% of employees are approaching retrenchment

- Most employees live very close to the office, indicating lower commute challenges

- Workforce has a healthy gender distribution
